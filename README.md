# Zuuno

A clinician-grade medical assistant and resource hub for people managing a
known diagnosis. Built for the Web Development Capstone as a plain
HTML / CSS / JavaScript web app.

## Run it

No build step or install is needed. Open `index.html` in any modern web
browser (double-click the file, or drag it into a browser tab).

## Files

- `index.html` — page structure and content
- `style.css` — visual design and layout
- `script.js` — interactive behavior (added milestone by milestone)
- `assets/` — icons and images
- `docs/version-log.md` — the running version log

## Milestones

1. **Front-End Skeleton** — visual layout and CSS style; buttons/tabs exist
   but are not interactive yet. *(current)*
2. **The Moving Engine** — JavaScript wired up: tab navigation, inputs, state.
3. **The Functional MVP** — the core feature working end-to-end, ready for
   peer playtesting.

See `docs/version-log.md` for the detailed change history.
